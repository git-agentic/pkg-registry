# Sentinel v0.1.0-alpha.3

> ⚠️ **Alpha, pre-1.0.** Not production-ready; APIs may change without
> notice between prereleases.

A security release. A full audit of Sentinel found ways for a package
author, a lockfile, an HTTP client or a sandboxed install script to get past
the checks Sentinel promises. This release closes them, then closes four
follow-up detection gaps in install-script analysis. ADR-0056 records each
decision.

## Install

```bash
npm install -g @git-agentic/sentinel-cli@alpha @git-agentic/sentinel-proxy@alpha
```

## Upgrade notes (breaking, pre-1.0)

- The proxy and the steward listen on `127.0.0.1` by default. A deployment
  reached over the network must set `SENTINEL_HOST` (proxy) or
  `SENTINEL_STEWARD_HOST` (steward).
- `SENTINEL_POLICY` must be exactly `observe` or `block`; anything else stops
  startup.
- In open mode, history import and retraction need `SENTINEL_PUBLISH_TOKENS`.
- `sentinel install --enforce` needs npm 7 or newer for dependency scripts,
  and refuses packages npm records only with a sha1 hash.
- A lockfile entry from git, from a URL, or with no integrity hash now
  blocks `audit-tree`. Older yarn v1 lockfiles from private registries can
  hit this.
- Steward: challenges expire after 30 days and are single use. After the
  upgrade, every challenge verified before it counts as used, so pending
  approvals, transfers, renewals and rulings need a fresh challenge. Claims
  linked only through a same-named GitHub or GitLab org now go through the
  Tier-2 review.
- `ClaimSteward.approve` is async, and transfer signing takes the current
  challenge id.
- Cached audits are re-run once after upgrading (`AUDIT_REVISION` 6).

## Fixed

**Scanner** (#84)

- Tarballs are read the way npm installs them: type-7 entries, npm path
  normalization, both readings of a backslash, PAX paths and trailing
  separators. A second or hidden root `package.json` raises a critical
  `manifest-confusion` finding.
- JavaScript that starts with a magic-byte label is still scanned. Nested
  compression counts against the unpack cap. One malformed field no longer
  disables a rule, and the regexes on the request path are linear.

**Trust inputs** (#84)

- Trusted-publisher repository and ref come from the Fulcio certificate,
  not the signer-written predicate. An unmatched signature key id counts as
  unsigned. Every SRI token in a lockfile is verified.

**Proxy** (#84)

- The npm compatibility routes no longer forward client credentials
  upstream, and their bodies are capped.

**Sandbox** (#84)

- The macOS profile is passed inline instead of through a temp file a
  script could rewrite.
- On Linux, bubblewrap gets its own pid namespace and session, and masks
  local IPC sockets (session bus, Docker and other container runtimes).
- `launchctl`, `open`, `systemd-run` and similar tools are carved out.
- Enforced installs bind each dependency script to its audited integrity.

**Steward** (#84)

- Tier 1 needs a homepage or repository host under the claimed domain.
- Disputes survive freezes, and transfer signatures bind the current proof.

**Action, CLI and CI** (#84)

- The Action escapes workflow commands and Markdown, and the CLI strips
  terminal escapes.
- The release workflow installs third-party code only in a job with no token.

**Install-script analysis** (#89, #90, #91, #92)

- A hook that calls `npm`, `pnpm`, `yarn` or `bun` is followed into the
  package's own scripts, including `pre`/`post` hooks and npm's aliases.
- Scripts run through `source`, pipes, `/usr/bin/env`, `tsx`/`ts-node` or
  `node .` are scanned.
- Preloads and command names served by the package's own bundled
  `node_modules` are scanned. Node built-ins are excluded.
- Very deep code no longer drops the native-payload loader check into a
  name-matching fallback; the loader-chain analysis now walks the syntax tree
  iteratively.

**Dependencies** (#84)

- Production advisories are fixed (body-parser, hono, fast-uri, qs, zod);
  `npm audit --omit=dev` reports none.

## Known limits

Recorded in ADR-0056 and the threat model: abstract unix sockets stay
reachable on Linux when `network` is approved, a sandboxed process can
outlive its script on macOS, and a few narrow shell-parsing corner cases in
install-script analysis.
